How to Use This Feature
  1. Enter City Name: Type a major city name (e.g., "Lucknow", "Delhi", "Mumbai", "Bangalore")
  2. Choose Search Radius: Select how far to search (5-20 km recommended)
  3. Click Search: The system will find hospitals in that area
  4. View Results: See hospital names, addresses, distances, and contact info
  5. Use Map: Click map icons to see exact locations
  6. Get Directions: Click Google Maps or OpenStreetMap buttons for navigation

Technology: This feature uses OpenStreetMap Nominatim API for geocoding city names to coordinates, and Overpass API for querying hospital data. Results depend on OpenStreetMap community data coverage in your area.
