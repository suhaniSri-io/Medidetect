Project Overview

What is MediDetect?

MediDetect is an educational project that demonstrates the application of machine learning in healthcare. It provides an intelligent symptom analysis tool that uses artificial intelligence to predict possible health conditions based on user-reported symptoms.

Key Features
AI-Powered Analysis

Random Forest machine learning model for prediction

19 Common Symptoms

Comprehensive symptom selection

7 Disease Categories

Covers common health conditions

Hospital Finder

OpenStreetMap integration for nearby hospitals

Technology Stack

Backend
  • Python 3.12 - Server language
  • Flask 2.3.3 - Web framework
  • scikit-learn 1.3.2 - Machine learning
  • NumPy & Pandas - Data processing
Frontend
  • HTML5 - Markup
  • Bootstrap 5 - Styling
  • JavaScript - Interactivity
  • Jinja2 - Templating
Machine Learning Model
  • Algorithm: Random Forest Classifier
  • Training Samples: 140 (20 per disease)
  • Features: 19 symptoms
  • Classes: 7 disease categories
  • Train/Test Split: 80/20

Learning Outcome

This project demonstrates practical implementation of:

  • Machine Learning: Random Forest classifier for multiclass prediction
  • Web Development: Flask backend with Jinja2 templating
  • UI/UX Design: Responsive Bootstrap-based interface
  • API Integration: OpenStreetMap API for hospital location
  • Data Processing: NumPy and Pandas for feature encoding
  • Database Management: CSV-based data storage
